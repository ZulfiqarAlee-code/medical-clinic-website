# 🏥 Medical Website

A responsive **Medical Clinic Website** built using **HTML5, CSS3, Bootstrap 4.6.2, Font Awesome, and JavaScript**.  
The website contains multiple pages including Home, About Us, Services, Portfolio/Team, Features, Contact Us, Sign Up, and Login.

---


## 📌 Project Overview

This project is a simple medical/clinic website template designed to provide information about a medical organization and its services.

The website includes:

- Responsive navigation menu
- Home page with a medical-themed hero section
- Clinic/About Us section
- Medical services section
- Team members/portfolio section
- Features section
- Contact form with JavaScript validation
- Google Maps integration
- User registration form
- Login form
- Form validation using JavaScript
- Responsive layout using Bootstrap

---

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and layout
- **Bootstrap 4.6.2** – Responsive design and grid system
- **Font Awesome 6.4.0** – Icons
- **JavaScript** – Form validation
- **Google Maps Embed** – Location/map section
